# AnimoReader

PWA para armar tu estado mental en una oración e imaginar el del otro.

## Publicar en GitHub Pages
1. Subí todo el contenido de esta carpeta a un repositorio (en la raíz).
2. En GitHub: Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save.
3. Abrí `https://TU-USUARIO.github.io/NOMBRE-REPO/` en el celular y elegí "Instalar" o "Agregar a pantalla de inicio".

Si cambiás archivos, subí el número de `CACHE` en `sw.js` (por ejemplo `animoreader-v2`) para que se actualicen en los dispositivos.
